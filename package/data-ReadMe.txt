Put the Commander Keen data files in this drawer, with the names they have
on the PC (AUDIO.CK4, EGAGRAPH.CK4, GAMEMAPS.CK4 and so on).

- Keen 4 was released as shareware and may be shared: 4keen14.zip (the
  file Omnispeak's own tests use, https://davidgow.net/keen/4keen14.zip).
- Keen 5 and 6 are commercial: use your own copy (for example the Commander
  Keen Complete Pack sold by GOG and Steam).

Only the data files are needed; the DOS programs are not.
